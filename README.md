# E-Commerce Data Visualization

Data analysis and interactive visualization project based on an e-commerce
orders and transactions dataset.

## Project Objective

The objective of this project is to explore, analyze and visualize
e-commerce data in order to identify useful patterns and insights
about customers, orders, products and sales.

## Dataset

The dataset contains 200,000 e-commerce transactions and 50 variables.

The original CSV dataset is not included in this repository because of
its large file size.

## Technologies

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
- Streamlit
- Git & GitHub
